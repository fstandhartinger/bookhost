# First week at Northwind Studio

This onboarding page is fictional training material for the Northwind Studio showcase workspace.

## Day one

1. Read the Studio Handbook and ask Mira Chen or Avery Brooks about anything unclear.
2. Review the current project brief before joining a client call.
3. Add questions to the project page instead of keeping decisions in private notes.
4. Check your BookStack role with a workspace administrator before creating or publishing pages.

## By the end of the week

- Shadow one project review and write a short summary for the team.
- Find the release checklist and walk through it with Sam Patel.
- Suggest one improvement to a shared workflow; label it as a proposal until the team agrees.

## Information handling

Use only fictional material in this workspace. Real client files, contact details, credentials, and private correspondence do not belong in the showcase.
