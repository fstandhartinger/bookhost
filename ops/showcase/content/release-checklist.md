# Website release checklist

Fictional internal checklist for a Northwind Studio client-site handoff.

## Before review

- Confirm the approved design version and page list.
- Check desktop and mobile layouts against the signed-off brief.
- Verify sample links, labels, and image credits.
- List any content that still needs a client decision.

## Before handoff

- Confirm the client has access to the agreed project files.
- Check that the usage guide names the final assets and their intended locations.
- Record the release date, owner, and rollback contact in the project notes.
- Ask the client decision maker to confirm the final review.

## After handoff

- Save the approved handoff summary in the project book.
- Assign each remaining follow-up to one person and a check-in date.
- Do not store passwords, API keys, personal information, or production customer records in this wiki.
